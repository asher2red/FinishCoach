# Finish Coach 브랜드 가이드 반영

후속 요청으로 이미지 에셋은 유지하고 버튼·카드 색상은 단일 선택 테마로 통일했다. 기본 green과 6가지 색상 선택의 최신 정책은 [단일 색상 테마](THEMES.md)를 확인한다.

사용자가 제공한 브랜드 가이드의 시각적 방향을 기존 앱에 적용했다. 가이드 내 예시 화면은 디자인 참고로 사용하고, 목표/일정/더보기 같은 새 기능이나 내비게이션은 추가하지 않았다.

## 이미지와 브랜드

- 빨간 코치 모자와 흰색 F를 새로운 브랜드 마크로 제작하고 헤더에 적용했다. 제품명 `Finish Coach`, 가이드의 문구 `오늘도, 더 나은 나를 향해.`를 표시한다.
- 오늘: 빨간 타깃, 루틴: 민트 달력, 기록: 파란 체크, 프로젝트: 보라 폴더, 통계: 청록 막대, 설정: 분홍 기어. 알림 설정은 노란 벨을 사용한다.
- 내장 image_gen으로 개별 투명 PNG를 생성했다. 원본과 배포용 에셋은 모두 `assets/brand/`에 저장했다. 화면 아이콘은 192px, 약 18~33KB이며 기존 expo-image를 사용한다. 새 라이브러리는 없다.
- 앱 아이콘: `assets/brand/app-icon-1024.png` — 1024px 정사각형, 불투명 배경.
- Android 적응형 전경: `assets/brand/adaptive-safe-1024.png` — 투명 캔버스의 중앙 안전 영역에 모자를 배치.
- 헤더·시작 화면: `assets/brand/coach-cap-small.png`, 웹 파비콘: `assets/brand/favicon.png`.
- 전체 최종 프롬프트 세트와 에셋별 용도는 [이미지 제작 기록](../assets/brand/GENERATION.md)에 보관했다. CLI/API 키 기반 생성은 사용하지 않았다.

## 컴포넌트와 색상

`src/ui/tokens.ts`에서 기존 녹색 팔레트를 밝은 회색 배경·네이비 텍스트·코랄 강조로 교체했다. 가이드의 Primary/Success/Info/Warning/Purple/Gray 색을 브랜드 토큰으로 정의하고 각 메뉴의 표면·테두리·아이콘 받침 색을 정리했다. 어두운 모드에서는 같은 의미의 색을 어두운 표면과 밝은 글자로 바꾼다.

`src/ui/ActionIcon.tsx`는 단색 SVG 대신 입체 PNG를 원래 색으로 표시한다. 기존 공통 Button은 파스텔 타일, 체크·선택 테두리, hover·focus·pressed·disabled 처리를 유지한다. Card에는 tone을 추가해 루틴·프로젝트·요약·통계가 같은 형태를 공유하면서 표면만 구분한다. CardTitle은 기존 제목과 아이콘을 정렬한다. `BrandMark.tsx`는 공통 헤더 브랜드 표시다.

가이드의 밝은 코랄색은 이미지·브랜드 토큰에 유지했다. 작은 버튼 글자의 대비를 위해 실제 선택 액션 표면에는 진한 코랄을 사용한다. 검사한 텍스트/카드, 보조 텍스트/배경, 선택 액션, 각 tone의 글자/표면 조합은 모두 4.5:1 이상이다(밝은 테마 최소 4.65:1, 어두운 테마 최소 7.99:1).

## 검증 범위

- ESLint·TypeScript 통과.
- Vitest 31개 통과.
- Chrome E2E 6개 통과: 기존 저장·완료·기록·프로젝트·날짜·시간·설정 흐름, 320/390/1280px, PNG 로딩, 키보드 focus/Enter, 선택 상태, 다크 모드·모션 감소 환경.
- Web 정적 export 및 Android/iOS Hermes 번들 생성 성공. 배포용 PNG만 화면 번들에 포함되며 큰 생성 원본은 UI에서 로딩하지 않는다.
- Expo CNG로 Android/iOS 프로젝트 생성 성공. iOS 앱 아이콘·스플래시 이미지셋과 Android 적응형 아이콘 리소스 생성 확인. 네이티브 파일을 수동 편집하지 않았다.
- 이번 브랜드 버전은 실기기/시뮬레이터에 재설치하지 않았다. 기존 APK·IPA·설치본은 이전 디자인이며 홈 화면 아이콘·시작 화면까지 확인하려면 새 네이티브 빌드가 필요하다.

데이터 모델·DB·상태·라우팅 핸들러·알림 동작·저장 로직은 변경하지 않았다. app.json의 변경은 이미지 경로와 시작 화면 배경·이미지 크기뿐이다.
