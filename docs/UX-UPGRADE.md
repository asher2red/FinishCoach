# UI/UX 개선 결과 · 2026-10-18

## 구현 범위

Expo SDK 58 / React Native 0.88 / Expo Router를 유지했다. 기존 루틴·예정·완료·프로젝트 모델과 저장소를 재사용했으며 외부 UI·차트 패키지는 추가하지 않았다.

### 날짜와 시간

- 루틴 시작/종료/일회성 실행일, 프로젝트 시작/목표일, 기록 조회일, 완료 기록의 날짜를 공통 월간 달력으로 변경했다.
- 달력은 월 이동, 오늘 강조, 선택 강조, 오늘/내일/다가오는 월요일 빠른 선택, 선택 날짜 표시, 확인/취소, 선택적 날짜 지우기를 제공한다.
- 종료/목표일 선택기는 시작일 이전 날짜를 비활성화한다. 시작일을 늦춰 기존 종료일이 앞서게 된 경우 자동으로 기록을 변경하지 않고 기존 도메인 저장 검증에서 오류를 표시한다. 선택기에서도 잘못된 종료일은 확인할 수 없다.
- 반복 현지 시각은 기존 `HH:mm`, 날짜는 `YYYY-MM-DD`, 실제 완료 시점은 ISO UTC를 유지한다. 불필요한 UTC 변환 없이 날짜를 선택한다.
- 오전·오후 / 1~12시 / 00~59분을 각각 선택한다. 모바일은 React Native ScrollView 스냅 휠과 탭, 접근성 증가/감소 동작을 제공한다. 웹은 스크롤 스냅 목록과 마우스·터치·방향키·Home/End를 제공한다.
- 07:30, 12:00, 20:15, 23:00 프리셋을 제공한다. 프리셋은 휠 위치와 선택값을 함께 바꾼다. 지우기 역시 확인 전에는 원본 값에 반영하지 않는다.
- 시간 표시와 저장값이 일치하도록 오전 12시=00시, 오후 12시=12시 변환을 분리했다. 완료 날짜/시각도 동일 선택기를 사용한다.
- 모바일 선택창은 화면 아래에, 웹은 중앙에 배치한다. 작은 화면은 내부 스크롤로 접근한다. 웹은 중첩 모달 애니메이션 동안 키보드 포커스가 바깥 폼으로 이동하지 않도록 선택창 애니메이션을 생략한다.
- 소요 시간은 10/15/20/30/45/60분 선택과 사용자 지정 입력, 주 N회 목표는 1~7회 선택을 제공한다. 루틴 일정과 알림은 기존 하나의 현지 시각 필드를 공유한다.

### 전역 알림 설정

`/settings`에 앱 전체 알림음·진동 설정을 추가했다. 변경은 저장 버튼 없이 기존 Repository 트랜잭션으로 저장하고 예약된 알림을 다시 구성한다. 저장 실패 시 화면은 기존 값을 유지하고 오류를 표시한다. 알림 예약만 실패한 경우 데이터 저장 성공과 예약 재시도 안내를 구분한다.

| 플랫폼  | 알림음      | 진동             | 한계                                                                                    |
| ------- | ----------- | ---------------- | --------------------------------------------------------------------------------------- |
| Android | 지원        | 지원             | 네 조합에 고정된 4개 채널 ID 사용. 사용자의 채널 변경·무음·방해 금지·제조사 정책이 우선 |
| iOS     | 지원        | 독립 제어 미지원 | 진동 스위치를 비활성화하고 시스템 설정을 따름을 안내. 저장된 Android 진동 값은 보존     |
| Web     | 제어 미지원 | 제어 미지원      | 두 스위치를 비활성화하고 브라우저 제한을 안내. 기존 열린 페이지 알림 기능은 유지        |

Android 채널은 `routines-v2-s0-v0` ~ `routines-v2-s1-v1`만 사용한다. 매번 새로운 임의 ID를 생성하지 않는다. 기존 `routines` 채널은 사용자의 OS 설정을 보존하기 위해 삭제하지 않지만 새 예약에는 사용하지 않는다. 채널별 소리와 enableVibrate, 구형 Android용 content sound/vibrate를 함께 지정한다. 음소거에도 알림은 유지한다. Android 전경 핸들러의 shouldPlaySound=false가 배너를 숨길 수 있으므로 Android에서는 채널과 content로 음소거하고 전경 표시는 유지한다.

iOS의 일반 로컬 알림은 앱이 진동을 소리와 독립적으로 설정할 수 있는 API를 제공하지 않으므로 작동하는 것처럼 표시하지 않는다. 앱은 무음·집중 모드를 우회하지 않는다. 알림 권한, 정확한 알람 권한 확인, best-effort 전달, 가까운 60개 예약, 앱 재개 시 복구 전략을 유지했다.

예약 작업은 서비스 내부에서 직렬 실행하고 기존 예약을 취소한 뒤 같은 occurrence UUID로 재예약한다. 알림음·진동 변경은 새 예약에 적용되며 중복 식별자로 예약을 늘리지 않는다. 설정 저장과 알림 예약은 다른 책임으로 유지한다.

### 기록과 통계

- 기록 화면에 이번 주 완료 횟수·실제 실행 시간·주간 목표 달성률·조회 주간의 실행일을 표시한다. 매일 실행을 요구하는 연속 일수는 계산하지 않는다.
- 전체/개별 활동 및 일/주/월/년 필터를 제공한다. 월 이동은 30일 덧셈 대신 실제 달력의 월·말일/윤년을 처리한다.
- 월~일 완료/예정 비교 그래프를 제공한다. 주 N회 목표는 날짜별 예정에 배정하지 않는다. 날짜를 누르면 해당 날짜의 기록 목록으로 연결된다.
- 활동별 횟수, 최근 6주 실제 시간, 연간 조회 시 12개월 실제 시간, 해당 주의 활성 주 N회 목표 달성 그래프를 제공한다.
- 새 완료 기록에는 계획 소요 시간을 실제 소요 시간으로 자동 복사하지 않는다. 실제 시간은 기록 수정에서 입력한다. 이전 버전의 actualDurationMinutes 값은 출처를 역추정하거나 삭제하지 않고 보존한다.
- 시간이 null인 기록은 0분으로 간주해 합계에 더하지 않으며 예상 소요 시간으로 보충하지 않는다. 완료 횟수에는 포함한다.
- 주간 목표가 없는 루틴은 주간 목표 달성률에 포함하지 않는다. 목표가 없으면 ‘목표 없음’을 표시한다. 초과 달성은 100%를 넘을 수 있다.
- 실제 완료 기록 목록은 날짜별로 유지하고 수정·취소를 제공한다. 처음 50개를 표시하고 더 보기로 추가한다. 그래프는 현재 화면에 표시한 50개가 아닌 선택 기간의 전체 기록을 집계한다.
- 집계 함수와 UI를 분리하고 useMemo로 재사용한다. 기록과 시간대 경계는 기기 현지 날짜 기준이다. 표제·날짜·수치·단위·선택 상세 및 빈 안내로 색상에만 의존하지 않는다.
- 과거 주간 목표를 조회할 때는 현재 저장된 루틴 규칙을 적용한다. 목표 횟수 변경 전의 이력을 추정하지 않는다. 루틴 규칙의 버전별 과거 목표 복원은 후속 범위다.

## 데이터 보존

스키마의 파괴적 변경은 없다. State version 1에 선택적 settings를 추가했다. 기존 데이터에 설정이 없으면 소리/진동 기본값을 true/true로 보완한다.

SQLite는 기존 DB 파일과 테이블을 유지하고 `CREATE TABLE IF NOT EXISTS app_settings`로 별도 테이블을 추가한다. IndexedDB는 기존 metadata 스토어의 settings 키를 사용해 DB 버전을 올리거나 스토어를 재생성하지 않는다. 설정과 도메인 데이터는 같은 트랜잭션으로 저장한다. 기존 필드·UUID·날짜·실행 시점은 유지한다.

## 검증과 한계

타입 검사·린트, 자동 테스트 31개, America/New_York 시간대에서 같은 31개, 실제 Chrome E2E 4개를 실행했다. E2E는 달력 선택/취소/최소일, 키보드 00:01 선택, 실제 휠 스크롤·탭, 시각 지우기 취소, 루틴 저장/재조회/reload, 기록 그래프 수치, 웹 설정 제한, 기존 프로젝트·완료·기록 수정 및 다크 모드를 검증한다. Android/iOS는 Expo Hermes 번들 생성까지 검증했다. SDK 호환성 검사는 설치된 SDK 맵에서 일치함을 확인했으며 새 의존성은 추가하지 않았다.

실제 Android/iOS 앱 구동 및 소리·진동 전달은 이 환경에서 검증하지 못했다. 이번 변경으로 새 APK/IPA를 생성하지 않았으므로 기존에 받은 APK에는 이 개선이 반영되지 않는다. iOS 진동과 웹 소리·진동 독립 제어는 플랫폼 제약으로 제공하지 않는다.

## 추가 수동 검증

- Android 기기에서 네 조합 각각으로 2~3분 뒤 알림을 예약해 전경/백그라운드/잠금 화면에서 표시·소리·진동 확인.
- 알림음과 진동을 모두 꺼도 알림 표시 유지, 기존 예약 수정 후 이전 소리·진동이 남지 않는지 확인.
- 네 조합을 반복 변경해 OS 채널이 네 개 이상 새로 늘어나지 않는지 확인. 사용자가 직접 채널을 수정한 경우 시스템 설정이 우선함을 확인.
- 기기 권한 거부/철회/재허용, 무음·방해 금지·제조사 절전 정책 확인.
- iOS 실제 기기에서 소리 ON/OFF 및 집중 모드, 진동 스위치 비활성 안내, 시스템 진동 설정 확인.
- 모바일 휠의 빠른 스와이프·정지 직후 확인·탭, TalkBack/VoiceOver 증가/감소, 큰 글씨, 작은 화면 확인.
- 시작/종료일, 일회성, 프로젝트 목표일, 완료 날짜 수정, 월말·윤년·DST·해외 시간대 변경 확인.
- 기존 앱 데이터가 있는 기기에 업데이트 설치하고 루틴·기록·마일스톤과 새 설정의 재시작 후 보존 확인.

참고: [Expo SDK 58 Notifications](https://docs.expo.dev/versions/v58.0.0/sdk/notifications/), [Apple notification sound](https://developer.apple.com/documentation/usernotifications/unmutablenotificationcontent/sound).
